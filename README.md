# いろぬりの森｜アプリサポート

iPhoneで遊べる、なぞり遊びとぬりえのゲームです。

**ぬりえの続き**　ホームの「ぬりえ」から同じ絵を選ぶと、前にぬった状態で開きます。作品は遊んだ端末に保存されます。アプリを削除すると作品も削除されます。

**かくれた絵の見つけ方**　「なぞってみつける」で白い紙をなぞり、絵の部分の90％以上を見つけると、全体と名前が現れます。

**保護者の方のお問い合わせ**　不具合の起きた画面・操作・iPhone機種・iOSバージョンをお知らせください。GitHubアカウントが必要です。投稿は一般公開されるため、個人情報やお子さまの写真を載せないでください。[問い合わせ窓口](https://github.com/leechco1050328-code/nazotte-forest-support/issues/new)
